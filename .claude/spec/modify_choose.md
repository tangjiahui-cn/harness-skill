# 选项编号样式修改规格

将 `skills/spec-create-harness/SKILL.md` 中所有步骤选择提示的编号样式从 emoji 数字（`1️⃣ 2️⃣ 3️⃣ 4️⃣ 5️⃣`）改为纯文本数字（`1. 2. 3. 4. 5.`）。

---

## 1. 需求背景

当前 SKILL.md 中所有用户选择界面的选项编号使用 emoji 样式（如 `1️⃣ 继续`），此类 emoji 在不同终端、不同字体下渲染效果不一致，部分环境可能出现显示异常或无法渲染的问题。改为纯文本格式可提高兼容性和可读性。

## 2. 修改范围

涉及人机交互的**用户选择提示**中的 emoji 数字编号，共 **6 处**（详见 3.1）。修改时仅替换编号本身（`1️⃣` → `1.`），保留编号后的文本内容和缩进格式。

### 2.1 修改规则

| 修改前 | 修改后 | 说明 |
|--------|--------|------|
| `1️⃣` | `1.` | 编号后数字 + 英文句点 + 空格 |
| `2️⃣` | `2.` | 同上 |
| `3️⃣` | `3.` | 同上 |
| `4️⃣` | `4.` | 同上 |
| `5️⃣` | `5.` | 同上 |

### 2.2 不修改的范围

以下内容保持原样，不做修改：

- **状态/进度标记 emoji**：如 `✅`、`❌`、`🎉`、`📐`、`🔍`、`⚠️`、`🟡`、`🔴`、`🟢` 等——这些是状态图标而非选项编号
- **纯文本编号**：如步骤说明中的 `1.`、`2.`、`3.`（已为文本格式的保持不变）
- **代码块和注释中的内容**：保持原样

## 4. 验收标准

1. **全文无 `[0-9]️⃣` 模式**：文件中不再出现任何 emoji 数字序号（`1️⃣` ~ `9️⃣`）
2. **纯文本编号格式统一**：所有用户选择选项格式为 `> N. 文本`（数字 + 英文句点 + 空格）
3. **非选择类 emoji 保留**：`✅`、`❌`、`🎉`、`📐`、`🔍`、`⚠️`、`🟡`、`🔴`、`🟢` 等状态图标不被误改
4. **缩进和格式不变**：所有选择的相对缩进关系、后续文本内容、Markdown 格式保持不变
5. **一致性说明更新**：第 147 行的交互要点中关于编号格式的说明同步更新

## 5. 不涉及的变更

- 不修改 SKILL.md 中除选项编号外的任何内容
- 不修改其他文件
- 不影响工作流的逻辑和行为
